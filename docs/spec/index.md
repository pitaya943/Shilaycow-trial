# Spec

一個小型的待辦事項 HTTP 服務:新增、列出、標為完成、篩出逾期的待辦。資料存在一個 SQLite 檔案,重啟後還在。

這份規格是 priority 任務時第一次從測試與實際操作整理出來的;標 *(未實測)* 的是讀程式推得、沒有實際跑過的。

## Areas

- [todos.md](todos.md):待辦事項本身,與存放它們的資料檔。

## Terms

- **待辦**:一個標題、是否完成、可有可無的到期日、一個優先順序,和服務給的編號。
- **優先順序**:`low`、`normal`、`high` 三者之一。
- **逾期**:還沒完成,而且到期日早於服務所在機器的今天。
- **資料檔**:服務啟動時用的 SQLite 檔;由 `TODO_DB` 指定,沒指定就是啟動目錄的 `todos.db`。

## What it deliberately does not do

- 沒有使用者與權限:任何能連到服務的人都能讀寫。
- 不能修改或刪除待辦(只能標為完成);不能改優先順序。
- 不依優先順序排序或篩選;列表一律照新增順序。
- 不支援把資料檔降級給較舊的版本使用。
