# 待辦事項服務

狀態:草稿,等 Owner 核准。

## 目標

一個小的 HTTP 服務,讓使用者新增待辦事項、列出它們、把其中一筆標為完成。

## 不做什麼

- 登入與多使用者:所有人共用同一份清單。
- 刪除、編輯標題、把已完成的改回未完成。
- 資料庫:資料存在記憶體,服務重啟後消失。
- 網頁介面與部署。

## 情境

### S-1 新增一筆待辦
Given 服務正在執行
When 我送出一筆待辦,標題是「買牛奶」
Then 我得到這筆待辦:有一個編號、標題是「買牛奶」、狀態是未完成

### S-2 列出待辦
Given 我已經依序新增「買牛奶」與「繳電費」
When 我要求列出所有待辦
Then 我得到這兩筆,順序與新增時相同

### S-3 標為完成
Given 有一筆未完成的待辦
When 我把它標為完成
Then 之後列出待辦時,這一筆顯示為已完成,其他的不變

### S-4 空白的標題
Given 服務正在執行
When 我送出一筆標題是空白的待辦
Then 我被告知標題不能是空白,而且清單沒有多出任何東西

### S-5 不存在的待辦
Given 清單裡沒有編號 999 的待辦
When 我把編號 999 標為完成
Then 我被告知找不到這筆待辦

## 怎麼試

啟動服務後,用任何能送 HTTP 請求的工具(例如 curl)依序做 S-1 到 S-5,對照每個情境的 Then。

## 預算

2 小時、10 個 session。到了就停下來報告,不論做完與否。

- 編號由服務產生,從 1 開始遞增。
