# T-02 標為完成

Status: done
Milestone: M1
Depends on: T-01

## 做什麼

依 `docs/tasks/todo-api/design.md` 做出 `POST /todos/{id}/complete`:

- 編號存在:把那一筆標為完成,回 `200` 與該筆待辦(`done: true`);之後 `GET /todos` 顯示它已完成,其他筆不變。對已完成的再標一次也回 `200`。
- 編號不存在:回 `404` 與 `{"detail": "todo not found"}`。

做完後,把標為完成的步驟(S-3、S-5)補進 `.claude/skills/drive-todo-api/`(`SKILL.md` 與 `drive.sh`),照它實跑一次並留下證據(`docs/tasks/todo-api/evidence/T-02-drive.txt`)。

同時修掉 PR #2 驗證時發現的 `drive.sh` 缺陷:同一個埠連續執行兩次時,第二次會連到上一次還沒關完的服務(第一筆的編號變成 3、清單有四筆,而且 exit 0)。修好的標準:`for i in 1 2 3; do bash .claude/skills/drive-todo-api/drive.sh /tmp/d$i.txt >/dev/null; grep -m1 '"id"' /tmp/d$i.txt; done` 三次的第一筆都是 `"id":1`。
