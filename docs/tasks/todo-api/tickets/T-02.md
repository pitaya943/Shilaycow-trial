# T-02 標為完成

Status: open
Milestone: M1
Depends on: T-01

## 做什麼

依 `docs/tasks/todo-api/design.md` 做出 `POST /todos/{id}/complete`:

- 編號存在:把那一筆標為完成,回 `200` 與該筆待辦(`done: true`);之後 `GET /todos` 顯示它已完成,其他筆不變。對已完成的再標一次也回 `200`。
- 編號不存在:回 `404` 與 `{"detail": "todo not found"}`。

做完後,把標為完成的步驟補進 `.claude/skills/drive-todo-api/SKILL.md`(如果它還沒涵蓋)。
