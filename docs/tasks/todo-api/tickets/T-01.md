## 做什麼

1. 建立專案骨架:`requirements.txt`(fastapi、uvicorn、pytest、httpx)、`todo_api/` 套件、`tests/`。測試指令是 `python -m pytest -q`。
2. 依 `docs/tasks/todo-api/design.md` 做出:

   - 標題是空字串或只有空白時回 `422` 與 `{"detail": "title must not be blank"}`,清單不變。
3. 服務能啟動之後,用 `drive` skill 建立 `.claude/skills/drive-todo-api/SKILL.md`,並照它實際跑一次、留下證據。
