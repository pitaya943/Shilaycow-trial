# 待辦事項的到期日

狀態:草稿,等 Owner 核准。

## 目標

待辦事項可以有到期日,而且可以只列出已經逾期的。

## 不做什麼

- 修改已存在的待辦的到期日。
- 時間(幾點幾分)與時區:到期日只到「日」。
- 提醒或通知。
- 依到期日排序:列出的順序維持新增的順序。

## 情境

### S-1 新增時帶到期日
Given 服務正在執行
When 我新增一筆待辦「繳電費」,到期日是 2026-12-01
Then 我得到這筆待辦,上面有到期日 2026-12-01

### S-2 不帶到期日
Given 服務正在執行
When 我新增一筆待辦「買牛奶」,沒有給到期日
Then 我得到這筆待辦,它沒有到期日;其他都和以前一樣

### S-3 只看逾期的
Given 有四筆待辦:A 昨天到期、未完成;B 明天到期、未完成;C 沒有到期日;D 昨天到期、已完成
When 我要求只列出逾期的
Then 我只得到 A

### S-4 到期日的格式不對
Given 服務正在執行
When 我新增一筆待辦,到期日寫成「下週五」
Then 我被告知到期日的格式不對,而且清單沒有多出任何東西

### S-5 原本的功能不變
Given 上一個任務的五個情境(新增、列出、標為完成、空白標題、不存在的編號)
When 我照原本的方式操作
Then 結果都和以前一樣

## 怎麼試

用專案的 `drive-todo-api` 啟動服務,依序做 S-1 到 S-4,再跑一次原本的五個情境。

## 預算

2 小時、10 個 session。

## 謹慎程度

一般

## 假設(Owner 沒有說,我先這樣定)

- 到期日的格式是 `YYYY-MM-DD`。
- 「逾期」是指:到期日早於今天,而且還沒完成。今天到期的不算逾期。
- 「今天」以服務所在機器的日期為準。
